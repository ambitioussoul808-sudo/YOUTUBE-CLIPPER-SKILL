## Pre-post checklist (both samples)
- [ ] Silent file on TikTok and Reels, with the trending sound added in-app. The YouTube file keeps the built-in track
- [ ] Custom cover set on every platform
- [ ] "Real-world footage" note is in the caption (it's also on screen in Sample 2). This keeps viewers from feeling misled and protects against "misleading content" flags
- [ ] Pexels credits are in the YouTube descriptions (not required, but good practice)
- [ ] Pinned comment or first comment posted within 1 minute
- [ ] Reply to the first 20 comments within the first hour. That's the strongest early reach signal on all three platforms
- [ ] Log views at 2h / 24h / 72h in the next scout CSV so the agent learns what works for **your** audience
